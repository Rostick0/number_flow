# Task: Develop Number Flow — Mobile Puzzle Game

Ты — опытный Flutter-разработчик и Game Designer, специализирующийся на создании мобильных casual-игр с высокой удерживаемостью игроков и монетизацией через рекламу.

Твоя задача — разработать полноценную мобильную игру **Number Flow** для Android на Flutter.

## 1. Концепция игры

Number Flow — это головоломка с числами, которые перемещаются по игровому полю.

Игрок должен объединять одинаковые числа, освобождать пространство и не допускать переполнения поля.

Основная игровая идея:
- На игровом поле появляются числовые блоки.
- Блоки перемещаются по определённым правилам.
- Игрок взаимодействует с ними, объединяя одинаковые числа.
- При объединении нескольких одинаковых чисел они превращаются в одно число большего номинала.
- Освободившиеся клетки позволяют продолжать игру.
- Чем дольше игрок продержится, тем выше будет его результат.

Игра должна быть простой для понимания, но сложной для достижения высоких результатов.

## 2. Игровая механика

Разработай собственную интересную механику, используя следующие базовые правила:

### Игровое поле
- Размер поля: 5x5 клеток.
- Каждая клетка может содержать число или быть пустой.
- Числа имеют визуальное оформление в виде цветных блоков.
- Новые числа появляются на свободных клетках.
- Игрок может перемещать блоки по полю согласно правилам игры.

### Объединение чисел
- Одинаковые числа можно объединять.
- При объединении трёх или более одинаковых чисел они превращаются в один блок следующего уровня.
- Пример: 2 + 2 + 2 = 4.
- После объединения освобождаются клетки.
- Цепные объединения должны быть возможны и приносить дополнительные очки.

### Перемещение чисел
- Реализуй плавное перемещение блоков.
- Продумай механику автоматического движения чисел.
- Движение должно создавать давление на игрока и заставлять его принимать решения.
- Добавь возможность стратегически управлять расположением блоков.

Важно: самостоятельно продумай и зафиксируй непротиворечивые правила движения, объединения и появления чисел до начала реализации. Не делай случайную смесь механик из разных игр.

### Система очков
- Очки за каждое объединение.
- Дополнительные очки за объединение нескольких блоков одновременно.
- Комбо-множитель за последовательные объединения.
- Рекорд текущей игровой сессии.
- Личный максимальный рекорд.

## 3. Прогрессия сложности

Игра должна постепенно становиться сложнее:
- Постепенно увеличивай скорость появления новых чисел.
- Увеличивай разнообразие числовых блоков.
- Добавляй дополнительные игровые ограничения на поздних этапах.
- Предусмотри систему уровней или бесконечный режим.

Игрок должен чувствовать постоянный прогресс, но не сталкиваться с резким скачком сложности.

## 4. Дополнительные механики

Предусмотри несколько бонусов:

1. **Undo** — отмена последнего действия.
2. **Remove** — удаление одного выбранного блока.
3. **Shuffle** — перемешивание чисел на поле.
4. **Double Merge** — удвоение результата следующего объединения.
5. **Slow Motion** — временное замедление движения чисел.

Бонусы должны быть ограничены по количеству и восстанавливаться за игровую валюту или просмотр rewarded-рекламы.

## 5. Игровые режимы

Реализуй:

- **Classic** — бесконечный режим, в котором нужно продержаться как можно дольше.
- **Time Attack** — ограниченное время на получение максимального количества очков.
- **Daily Challenge** — ежедневное испытание с одинаковыми начальными условиями для всех игроков.

Архитектуру сделай расширяемой, чтобы можно было добавлять новые режимы.

## 6. Визуальный стиль и UI/UX

Стиль: современный минималистичный casual puzzle.

Визуальные требования:
- Чистый интерфейс без визуального шума.
- Приятная цветовая палитра.
- Скруглённые блоки.
- Плавные анимации перемещения.
- Эффект слияния чисел.

- Небольшая вибрация при важных игровых событиях.
- Анимация получения очков.
- Адаптация под разные размеры экранов.

Цвета блоков должны различаться в зависимости от числового значения. Используй гармоничную прогрессию цветов.

## 7. Монетизация

Основная модель монетизации — бесплатная игра с необязательной рекламой.

Используй Yandex Mobile Ads.

Реализуй:
- Rewarded Ads для получения дополнительных бонусов.
- Rewarded Ads для удвоения награды после игры.
- Interstitial Ads между игровыми сессиями с ограничением частоты показа.
- Не показывай рекламу во время активного игрового процесса.
- Не заставляй пользователя смотреть рекламу для продолжения игры.

Предусмотри возможность отключения рекламы через внутриигровую покупку в будущем.

Все рекламные интеграции должны быть изолированы в отдельном сервисе. Игра должна полноценно работать, даже если реклама недоступна.

## 8. Игровая экономика

Добавь внутриигровую валюту — Coins.

Игрок получает монеты:
- За достижение определённых результатов.
- За ежедневные задания.
- За выполнение достижений.
- За просмотр добровольной rewarded-рекламы.

Монеты используются для покупки бонусов.

Экономика должна быть сбалансированной и не превращать игру в Pay-to-Win.
